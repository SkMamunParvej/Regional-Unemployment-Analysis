
# Unemployment Analysis with Python

## CodeAlpha Data Science Internship
Task 2 - Unemployment Analysis

## Project Description
This project analyzes unemployment trends
using Python and data visualization.

## Objectives
- Analyze unemployment rates
- Clean and preprocess data
- Visualize regional unemployment
- Study unemployment trends over time
- Explore the impact of COVID-19

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## How to Run
1. Install the required libraries.
2. Download the dataset.
3. Run unemployment_analysis.py.

## Results
The project generates charts showing
regional unemployment, unemployment
trends, and rate distribution.
